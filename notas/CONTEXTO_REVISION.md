## 3. GAPS IDENTIFICADOS

### Gaps en la literatura existente:
1. **México + EGC + informalidad**: Pocos papers usan modelos EGC con sector informal endógeno para México
2. **Transiciones formales-enformales**: Literatura sobre mobility occupational escasa para México
3. **CGV + informalidad**: Intersección几乎空白 - oportunidad de tesis
4. **Minimum wages + informalidad**: Pocos estudios combina ambos efectos con datos México
5. **Sorting matching**: Linked employer-employee data para México es limitado

### Oportunidades para tesis:
- **Propuesta 1** está bien servida por literatura existente
- **Propuesta 3** (CGV + formalización) es la más original
- **Propuesta 4** requiere modelado avanzado pero es muy novedosa
- **Propuesta 5** depende críticamente de acceso a datos
