## ROADMAP METODOLÓGICO DETALLADO POR PROPUESTA

### PROPUESTA 1: Detalle Econométrico

#### **Especificación Principal**

```
MODELO: DiD con exposición comercial variable continua

Ecuación:
Trans_ijt = β₀ + β₁·Exp_jt + β₂·Exp_jt·Post_t + δᵢ + λₜ + Xᵢⱼₜ'γ + εᵢⱼₜ

Donde:
- i = zona metropolitana
- j = industria  
- t = período
- Trans_ijt ∈ {U→F, U→I, I→F, I→U}
- Exp_jt = Exposición comercial industria j (continua, 0-1)
- Post_t = 1 si t > shock (ej. 2008)
- X = Controles: composición demográfica ZM
```

#### **Instrumentación**

```
PROBLEMA: Exp_jt puede ser endógeno (demanda endógena)

SOLUCIÓN: Usar importaciones China a otros países LAC como instrumento

IV First Stage:
Exp_jt^MX = α₀ + α₁·Exp_jt^{LAC-ex-MX} + ξⱼₜ

Donde Exp_jt^{LAC-ex-MX} = Importaciones industria j a Argentina, Brasil, Chile,
                             Colombia, Costa Rica, Panamá

SUPUESTO: China competition contra otros países LAC es exógeno a Mexico-specific
         shocks (plausible: China compete equally all LAC)
```

#### **Validación**

```
1. First-stage F-statistic > 10 (weak instrument test)
2. Overidentification test (J-test) si múltiples instrumentos
3. Falsification: Regresionar pre-shock transitions (1990-2000) en future exposure
   → Esperado coef. = 0 (evidencia exogeneidad)
4. Placebo tests: Usar industrias no-expuestas a competencia china
```

#### **Heterogeneidad**

```
MODELO INTERACCIÓN:

Trans_ijt = β₁·Exp_jt + β₂·Exp_jt·EduHigh_it + β₃·Exp_jt·FirmSize_jt + ...

INTERPRETACIÓN:
- β₂ > 0: Trabajadores educados absorben mejor shocks
- β₃ > 0: Firmas grandes tienen menos transición negativa
```

### PROPUESTA 2: Detalle Estructural

#### **Especificación Modelo Firma**

```
DINÁMICA FIRMA:

Estado: (z_t, ℓ_t, j_t)

z_t ~ AR(1): Δln(z) = ρ_z·Δln(z_{t-1}) + σ_z·ε_t

Decisión formalización:
ℓ* = argmax {π^F(z,j,M) - F_F, π^I(z,j,M) - F_I}

Donde:
π^F = [p(M)·y(z) - τ - c_r(z)]·L^F - w^F·L^F - c_entry
π^I = [p(M)·y(z) + ρ]·L^I - w^I·L^I - θ(M)·V

Restricciones:
- c_r(z) = c₀ + γ·z^ρ (compliance burden increasing in size)
- y(z) = z^α (production function)
- θ(M) = θ₀ + θ₁·M (closure probability increasing in imports)
```

#### **Calibración Objetivos (Targets)**

```
Momentos a Replicar:

1. Share empleo informal: E[I/(I+F)] = 0.50 (México)
2. Wage premium formal: E[w^F]/E[w^I] = 1.18 (15-20%)
3. Distribución tamaños: Log-normal con σ ≈ 1.5
4. Tasa salida firmas: Exit rate ≈ 3-4% anual
5. Share exportadores (formales): ≈ 10-15%
```

#### **Estimación (No Structural)**

```
REDUCED FORM ALTERNATIVA (si poco tiempo para structural):

Formalización_ijt = β₀ + β₁·ImportExp_jt + β₂·TFP_{i,t-5} + 
                    β₃·ImportExp_jt × TFP_{i,t-5} + 
                    β₄·ExportShare_jt + X'γ + μⱼ + εᵢⱼₜ

Ventaja: Directamente estimable OLS/IV sin calibración
Desventaja: No identifica mecanismos profundos
```

### PROPUESTA 3: Mapeo CGV

#### **Identificación Participación CGV**

```
MÉTODO 1: Usando Tablas Input-Output INEGI

Para firma i en industria j:
CGV_Share_i = (Inputs importados / Total inputs) × α_GVC

Donde α_GVC = Proporción de industria j que es part de CGV
             (Estimada de OECD TIVA o similar)

MÉTODO 2: Usando Trade Data y Producto

Para industria j:
    
Imported_Inputs_jt = Σ M_kt · s_k,j,t
                     k: input industries

Donde s_k,j,t = share de k inputs en producción j

Resultado: CGV measure = Imported_Inputs / Gross Output
```

#### **Shock CGV Exógeno**

```
CONSTRUCCIÓN:

GCV_Shock_jt = ΔWorld_Demand_GCV_j,t / Base_Sales_j,t-5

Donde World_Demand_GCV estimada de:
- OECD TIVA: Trade in Value Added
- World Bank GVC indicators
- O: Usar importaciones China a USA (competencia trade diversion)

SUPUESTO IDENTIFICACIÓN: Demand cambios are exógeno a firma-level decisions
                         (México es pequeño en mercado global)
```

### PROPUESTA 4: Calibración Melitz-Informal (Avanzado)

#### **Pasos Calibración**

```
PASO 1: ESTIMAR TFP FIRMA

OLS Proxy Variable:
ln(Y_ijt) = α_K·ln(K_ijt) + α_L·ln(L_ijt) + α_M·ln(M_ijt) + ω_ijt

Usar coeficientes factor shares como pesos:
α_K = 0.25, α_L = 0.65, α_M = 0.10 (típicos LAC)

Recuperar: ω_ijt = TFP_ijt + error (measurement error)

PASO 2: STOCHASTIC PROCESS TFP

Estimar AR(1):
ln(TFP_t) = ρ·ln(TFP_{t-1}) + σ·ε_t

De longitudinal changes entre censos

PASO 3: PARÁMETROS DEMANDA

Elasticidad substitución σ = 2-3 (típico manufactura)
Participación laboral en valor agregado = 0.60 (México)

PASO 4: COSTOS REGULACION

Estimar función c_r(z) usando:
- Costos compliance IMSS, SAT (datos públicos)
- Variación por tamaño firma

PASO 5: VALIDACIÓN

Simular modelo con parámetros calibrados, comparar:
- Distribución tamaños teórica vs. observada
- Participación formal vs. observada
- Salarios promedio formal-informal
```

#### **Contrafáctico Dinámico**

```
EXPERIMENTO: Reducción arancel 33% (2005-2010)

SIMULACIÓN:
1. Período inicial: Resolver equilibrio 2005
2. Shock: Introducir cambio precio M_jt
3. Ajuste: Simulación forward 2005-2010
   - Cada año: Entry decision (endógena)
   - Cada firma: Formalización decision
   - Transiciones: Firms between estados
4. Comparar trayectoria simulada vs. datos 2010

MÉTRICAS:
- Employment formal/informal (nivel, transiciones)
- TFP agregada (Olley-Pakes weighted)
- Salarios promedio
- Valor agregado por sector
```

### PROPUESTA 5: Linked Data Requerimiento

#### **Identificación Two-Way Fixed Effects**

```
MODELO:
ln(w_ijt) = α_i + ψ_j + u_ijt

Donde:
- α_i = worker effect (ability)
- ψ_j = firm effect (quality)
- u_ijt = match component

PROBLEMA: Simultaneidad selection
- Trabajadores ability-alta van a firmas quality-alta
- Impossível separar sin observación

SOLUCIÓN: Requiere movilidad workers entre firmas

IDENTIFICACIÓN: Usar movilidad para romper endogeneidad
- Si worker i cambia firma j → j', la diferencia salarial
  identifica (ψ_j - ψ_j')
```

#### **Requerimiento Datos**

```
LINKED EMPLOYER-EMPLOYEE DATA necesario:

Worker ID | Firm ID | Period | Wage | Education | Formal Status | Firm Size
---------|---------|--------|------|-----------|---------------|----------
001      | 100     | 2005   | 5.0  | 12        | 1            | 50
001      | 200     | 2006   | 5.2  | 12        | 1            | 100
002      | 100     | 2005   | 4.5  | 9         | 0            | 50
...

SOURCES México:
- IMSS registros (acceso restringido): Formal workers + firms
- SAT Nómina data (acceso restringido): Formal employees
- ENOE (público): Pero identidad firma no disponible

ALTERNATIVA: Usar ENOE + matching probabilístico con Censos
```

   - **Por qué:** Complemento: exportaciones pueden ser "formalizing force"

   - **Resultado clave:** Exportadores pagan más, requieren estándares
   - **Aplicabilidad:** México exportador (maquiladoras), contexto similar

   - **Aplicabilidad:** Framework para Prop 1 con fricción laboral
